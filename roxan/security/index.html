Open Roxan

Built to bechecked.

Plain statements about what Roxan stores, what it sends, how it is stopped from acting on its own, and what we are not claiming.

What stays on your device

Your conversation, notes, specialties, Handoffs, projects, reminders and the files you attach are stored in this browser. They are not stored on Oplo’s servers. The Vault is stored here too, sealed, and Oplo never has the key. If you clear this browser’s site data, all of it is gone; export first to keep a copy of everything except the Vault.

What leaves it

To write a reply, Roxan sends the recent conversation, the notes chosen for that message together with the names they are about, the specialties that fit it, whether learning is on, the project’s instructions, and any attachments in recent messages to a language-model provider through Roxan’s gateway. The reply says how many notes it was shown.

The gateway checks your invite code, applies limits, and passes the request on. It does not store or log the content of messages. The provider’s own handling of that content is governed by its terms, which Roxan cannot change.

Nothing from the Vault is ever part of a request. The code that sends requests does not contain the Vault’s code, and an automated test fails if that changes. Anything you type into a message does go to the provider, a card number included, which is why Roxan warns you before sending one.

How actions are controlled

Roxan can only use the actions it has been given, and each action has a fixed shape that is checked before anything happens. Text written by the model never counts as permission.

  • Actions that change something wait for your approval, showing exactly what will happen.
  • You can change a detail on a card before you approve it; what runs is exactly what the card showed when you pressed Approve. An unanswered approval expires after a day, and one approval allows one action.
  • If anything is missing, unclear or expired, the action does not run.
  • Roxan says an action is done only after it has been confirmed.
  • A Handoff is a written task. Saving one runs nothing, because no computer is connected, and it is marked done only when you say you did it.
  • The one thing kept without a yes is a short note or specialty learned while learning is on. It only writes words, is shown in the conversation with an Undo, and can be switched off in Settings.

Untrusted content

Files you attach, pages and other content Roxan reads are treated as data. They cannot change Roxan’s rules or grant it permission. Roxan can propose a note, and while learning is on a short note is kept at once, but never from a message with an attachment and never from anything that looks like a password, a card or a medical detail: those wait for your yes. Replies are shown as text and links; nothing in a reply is executed.

The Vault

Secured by OploCloud. Each item is sealed in your browser before it is saved: AES-256-GCM, with a key made from your passphrase and a random salt using PBKDF2 with SHA-256 and 600,000 rounds. The browser creates the key so that it cannot be exported, and it is held in memory only while the vault is open. Every item has its own random nonce, and its place is bound into the seal, so an item cannot be swapped or altered without opening failing. The vault locks after five idle minutes and when you leave its page, and it is never part of an export.

There is no reset, because nobody but you has the passphrase. Forget it and the items cannot be recovered.

What this does not cover:

  • The code that seals the vault is delivered by this website each time it loads, so you are trusting the code we serve, as with any web app.
  • While the vault is open, anything on this device that can read your screen or your browser, such as malware or a hostile extension, could read it too.
  • Anyone who gets a copy of this browser’s data can try passphrases offline. Four or more random words resist that; a short one does not.
  • No computer is connected yet, so nothing is filled into any website from the vault. That is the next step.

Your controls

Read, edit or delete any note, specialty or Handoff, and turn learning off. Delete a conversation, or a project with all of its conversations and attachments. Delete the Vault and everything sealed in it. Export your data (images and PDFs are listed, not included, and the Vault is left out), or delete everything in one step. Deleting removes the data from this device immediately.

What is not claimed

  • Roxan has no security certifications or independent audits yet, the Vault included. “Secured by OploCloud” names the feature; it is not a certification.
  • Messages are not end-to-end encrypted: the provider has to read the text to answer it.
  • Learning relies on a model’s judgement, so it can keep a note you did not want. That is why each is shown with an Undo.
  • Roxan cannot use a web browser yet. A Handoff is a saved task, and none has been run for anyone.
  • Reminders fire only while Roxan is open in a tab.
  • There are no accounts yet, so access is by invite code, and history is not shared between devices.
