Transparency Report

Zero is a number worth publishing.

Oplo has received no request from any government for anyone’s data.

Period covered

Since incorporation, to date.

Oplo has no users and holds no personal data, which is why every figure below is zero. Publishing it now sets the baseline: the first report that is not zero can be read against this one.1

Requests received

  • Government requests for account data0
  • Government requests for device data0
  • Emergency requests0
  • National security requests0
  • Requests to remove content0
  • Preservation requests0

Responses

  • Accounts affected0
  • Requests where data was produced0
  • People notified0 — none to notify

How a request would be handled

Written down before the first one arrives.

Deciding this in advance is easy. Deciding it while a demand is on the desk is not, which is the reason to do it now.

Require legal processA valid order for the specific data sought. A request by letter, phone call or relationship is refused.
Narrow itProduce the least that answers the order, and challenge one that reaches further than the law lets it.
Tell youThe person is notified before anything is produced, unless a court has forbidden it — and then as soon as that expires.
Hand over what existsContent encrypted with keys held on your device cannot be produced. That is a property of the design, not a position we could be argued out of.
Count it hereEvery request appears in the next report, including the ones refused.

Cadence

Twice a year, and on the day it changes.

This report is updated every six months once Oplo has users. If a request arrives before then, this page changes when the report on it can lawfully be published, rather than waiting for a schedule.
